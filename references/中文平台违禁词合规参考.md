## 四、数据集 Schema(若需导出为 YAML / JSON)

| 字段 | 说明 |
|---|---|
| `word` | 违禁词 |
| `category` | 类别:极限词 / 时政 / 色情 / 暴力 / 医疗 / 赌博诈骗 / 迷信 / 平台专属 |
| `platform` | 适用平台(公众号 / 小红书 / 抖音 / 通用,多值) |

| `suggestion` | 建议替换 |
| `context_note` | 语境说明(部分词持资质可用) |

> 以下为《广告法》明令禁止的绝对化用语示例,相对稳定;实际发布前仍应以 `multi-wordcheck` 实时校验为准。

> ⚠️ 此种子集非穷举;平台专项词(私域导流、站外引流等)变动频繁,务必走 `multi-wordcheck` 实时 API。

## 六、维护约定
1. 优先复用 `multi-wordcheck`,本文件仅兜底与记录。
2. 新增 / 下线词:新条目标 `status: active` 并填 `source` + `updated_at`;下线条目改 `status: deprecated`(保留原文留痕,注明日期 / 原因 / 替代);顶部 CHANGELOG 追加版本。
3. 平台公约大版本更新(如小红书 2.0)时,同步第三节「平台专属敏感点」(旧敏感点改 `deprecated`,不直接删除)。
4. 种子集(第五节)为法定稳定词,仅随《广告法》修订更新。
5. 第七节(声明 / 电商向)纳入周巡检:重点盯法规生效节点(如《AI 标识办法》配套细则)与平台执行阈值变动(如小红书蒲公英报备门槛、各平台 AI 声明入口);`pending-verify` 条目待官方源核实后转 `active`。
6. 垂类专项公约(如 7.3 小红书《社区金融生态公约》)与社区公约分开记:垂类公约升级不改动社区公约版本号,反之亦然;垂类公约细则纳入周巡检核验范围。

## 七、平台鼓励与不鼓励(声明 / 电商向,创作者视角)

> 用途:表情包上架描述之外的合规面——**发演示内容(AI 生成的 GIF / 图文)时的声明义务,以及后续商业化时的合规路径**。公约本体不常改,但本节执行层细则变动快,随周巡检更新。

### 7.1 声明类

| 层级 | 鼓励(合规做法) | 不鼓励(处罚) | 状态 |
|---|---|---|---|
| **法规:《人工智能生成合成内容标识办法》**(四部门,2025-09-01 施行) | AI 生成的文本/图片/音频/视频/虚拟场景均须标识:显式标识(用户可感知)+ 隐式标识(文件元数据);**用户发布时须主动声明并使用平台标识功能**;配套强制国标《网络安全技术 人工智能生成合成内容标识方法》同步施行(视频显式标识:文字高度≥画面最短边 5%、持续≥2 秒) | 恶意删除 / 篡改 / 伪造 / 隐匿标识,或为他人提供规避工具→依法处理 | `status: active`(官方源:https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm ) |
| **法规:《互联网广告管理办法》** | 种草 / 体验分享 / 消费测评等附加购物链接→显著标明「广告」 | 变相发布广告不标注→违法 | `status: active` |
| **小红书** | 发布时勾选「笔记含AI合成内容」 | 不声明→平台自动打「疑似AI生成」标(来源标注为平台识别,被动曝光) | `status: active`(多源证实) |
| **抖音** | 「发文助手自主声明」选「内容由AI生成」;平台对未标内容补标 | 未标→平台补显式标识 + 限流 / 下架 / 封号(部分平台明示) | `status: active`(《抖音关于升级AI内容标识功能的公告》,见新闻源 https://www.shx.chinanews.com/news/2025/0902/107060.html ) |
| **微信(视频号/公众号)** | AI 生成合成内容发布时主动声明(微信珊瑚安全公告) | 引起混淆误认→处罚 | `status: active`(同上新闻源) |

### 7.2 电商 / 商业合作类

| 平台 | 鼓励(官方通道) | 不鼓励(严打) | 状态 |
|---|---|---|---|
| **小红书** | 蒲公英报备 = 商单唯一合规路径,报备笔记自动带「合作/广告」标;可正常投流、挂商品链接 | 未报备软广:单次扣 4 信用分 + 笔记下架,扣满 10 分**永久清空带货/蒲公英/投流权限**;站外导流(微信号/二维码/谐音拆字):限流→封号→营业执照主体拉黑;滤镜夸大效果(医美护肤对比图)直接下架 | 阈值类数据 `status: pending-verify`(二手运营文,待官方源复核):2026-07 新规称寄样价值≥500 元须报备、品牌合作人门槛粉丝≥1 万 + 近 30 天单篇平均曝光≥5 万 |
| **抖音** | 官方变现:商品橱窗 / 小黄车 / 星图接单 | 恶意导流(第三方链接 / 二维码 / 带第三方水印内容)、虚假营销、无资质医疗金融内容(公约第 33/34 条) | `status: active`(官方公约) |
| **微信表情** | 赞赏走官方微信支付通道(个人零钱 / 企业商户号) | 上架描述夸大;推广类付费作品 / 特效作品不过审(免费表情可推广类,但不进商店展示) | `status: active`(官方 FAQ,2026-09-07 核实) |

> 通用规律:平台清一色鼓励「**官方通道内变现 + 主动亮明身份(AI 声明 / 商业报备)**」,严打「**站外导流 + 隐瞒利益关系 + 伪装素人**」。
> 对 skill 的落点:①产出 AI 生成的表情包演示内容发布到小红书 / 抖音 / 公众号时,必须勾选 / 声明 AI 生成;②后续若商业化,走各平台官方通道,勿在文案中引导站外交易。

### 7.3 金融营销专项:小红书《社区金融生态公约》(2026-09-15 发布,自发布日起试行)

> 小红书首份金融垂类专项公约,**不是社区公约 3.0**(社区公约仍 2.0,2026-01-20)。适用于所有在小红书发布 / 传播涉金融信息内容的账号。触发场景:做**金融向演示内容**(如"AI 帮我记账 / 理财"类笔记、金融主题表情包文案)。

**A. 八类禁区(明令禁止,`status: active`)**

| # | 禁区 | 具体表现 |
|---|---|---|
| 1 | 恶意唱衰 | 恶意唱衰宏观经济 / 资本市场,恶意炒作市场走势、臆测点位 |
| 2 | 非法荐股 | 明示或暗示个股买卖价、预测走势、分成跟投 |
| 3 | 宣传非法金融活动 | 为非法金融活动做宣传 |
| 4 | 编造虚假 / 不实信息 | 含 **AI 换脸造谣**、无信源爆料 |
| 5 | 收益误导内容 | "保本保息""稳赚不赔""低门槛高收益"等 |
| 6 | 伪造权威背书 | 伪造权威机构、国企或专业人士背书 |
| 7 | 变相站外导流 | 以资料包、理财课、私信拉群等方式导流站外 |
| 8 | 虚假金融人设 | 编造收益故事、仿冒身份打造虚假金融人设 |

**B. 鼓励什么(合规路径)**
- 有专业资质的创作者与金融机构可做宏观 / 投资理财科普;用户可分享**真实**理财经历
- 但须:充分风险提示、不得夸大收益或隐瞒风险、**使用 AI 生成或辅助生成金融信息应标注**并对准确性 / 时效性负责

**C. 金融营销:先持牌、再认证、后营销**
- 金融属特许经营行业;机构须提交金融管理部门核发的业务许可,证券 / 基金 / 期货 / 保险从业者须提交从业资质,完成平台专业认证并展示执业信息
- 未认证时,账号名称 / 头像 / 简介 / 背景图**不得使用"银行""证券""基金""保险"等涉金融属性字样**暗示持牌身份
- 冒名、挂靠、租买、伪造资质一律禁止;非金融机构不得无证经营,不得对私募产品、场外衍生品等开展违规网络营销
- 商业合作金融内容须通过平台商业化工具发布并显著标识,**不得以"个人经验"做隐性推广**

**D. 处置与执法**
- 梯度处置:限流 → 下架 → 封号;平台自述加强巡检、不利用算法诱导过度消费 / 投资
- 治理数据(近半年):处置违规笔记 **101 万+ 篇**、违规账号 **15.7 万+ 个**、违规评论 **477 万+ 条**;治理框架为"发现—识别—处置"三级,AI 大模型跨场景(笔记 / 评论 / 私信)判断真实意图,黑灰产团伙按 WiFi / IP / 群聊 / 账号关系聚类识别
- 后续法规:《金融产品网络营销管理办法》(八部委,2026-09-30 施行)——金融机构与第三方平台外的其他组织 / 个人不得开展金融产品网络营销

**E. 对本 skill 的落点**
- 表情包本体通常无金融属性,风险主要落在**演示笔记的文案与配图**:写"AI 理财 / 收益"类示例时,不得出现保本保息、收益数字承诺、荐股口吻、站外拉群话术
- 若做金融主题演示,AI 生成标识是**双重必需**(《AI 标识办法》+ 本公约均要求)
- 小红书这部分执行细则预计随周巡检跟进;`pending-verify`:公约全文 PDF / 官方规则页暂未见公开直链(现为媒体转述 + 小红书官方账号「财经薯」发布),待补官方锚点
