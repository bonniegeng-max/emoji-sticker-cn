# 中文平台违禁词合规参考

> 用途:作为 `emoji-sticker-cn` skill 的违禁词校验知识源与兜底。
> 维护方式:本文件持续更新。平台规则高频变动(抖音公约「随生态完善持续更新」,小红书 2026-01 发布公约 2.0)。实时校验依赖 `multi-wordcheck` API 无需巡检;仅平台公约大版本发布时,走 skill 的「规则更新与退出机制」更新本文件(旧说法改 `deprecated` 留痕,新说法 `active` 入库,CHANGELOG 追加)。
> 重要:实际校验**优先复用本机 `multi-wordcheck` skill**(覆盖公众号 / 小红书 / 抖音,调敏感词 API,返回 `platform` + `prohibitedWordsType`)。本文件仅作可维护参考与离线兜底,不替代实时 API。
> **条目生命周期**:`pending-verify` → `active`(生效)→ `deprecated`(退出留痕,禁止作为依据)。

  - 小红书社区规范(2.0):https://news.dayoo.com/finance/202601/20/171077_54918901.htm

## 三、平台专属敏感点(表情包文案 / 上架描述尤其要注意)

| 平台 | 严打项 |
|---|---|
| 公众号 | 时政资质、诱导分享(集赞 / 诱导转发)、医疗宣称 |
| 小红书 | 零容忍绝对化词;严打私域导流(留微信号);医美 / 医疗词 |
| 抖音 | 直播实时口播抓取;严查虚假库存营销、站外引流 |
| 微信表情 | 上架描述禁用夸大、侵权 IP、政治 / 色情内容 |

## 四、数据集 Schema(若需导出为 YAML / JSON)

| 字段 | 说明 |
|---|---|
| `word` | 违禁词 |
| `category` | 类别:极限词 / 时政 / 色情 / 暴力 / 医疗 / 赌博诈骗 / 迷信 / 平台专属 |
| `platform` | 适用平台(公众号 / 小红书 / 抖音 / 通用,多值) |
| `risk_level` | 高 / 中 / 低 |
| `suggestion` | 建议替换 |
| `context_note` | 语境说明(部分词持资质可用) |
| `source` | 来源 URL 或法规条款 |
| `updated_at` | 更新日期 |
| `version` | 词库版本 |

存储建议:分层(通用层 + 平台层 + 行业层如美妆 / 医美),便于版本控制与按平台增量加载。

## 五、通用极限词种子集(法定稳定,可作离线兜底)

> 以下为《广告法》明令禁止的绝对化用语示例,相对稳定;实际发布前仍应以 `multi-wordcheck` 实时校验为准。

国家级、最高级、最佳、第一品牌、唯一、顶级、极致、绝对、100%、万能、王牌、销量第一、全网最低、史上最、最优秀、最核心、最先进、最受欢迎、独家、首选、领导者、缔造者、创始者、世界领先、行业领先、无可替代、绝无仅有、前无古人、永久、终身、立即见效、彻底根治、100% 有效、包治、根治、无副作用(医疗类需资质)

> ⚠️ 此种子集非穷举;平台专项词(私域导流、站外引流等)变动频繁,务必走 `multi-wordcheck` 实时 API。

## 六、维护约定
1. 优先复用 `multi-wordcheck`,本文件仅兜底与记录。
2. 新增 / 下线词:新条目标 `status: active` 并填 `source` + `updated_at`;下线条目改 `status: deprecated`(保留原文留痕,注明日期 / 原因 / 替代);顶部 CHANGELOG 追加版本。
3. 平台公约大版本更新(如小红书 2.0)时,同步第三节「平台专属敏感点」(旧敏感点改 `deprecated`,不直接删除)。
4. 种子集(第五节)为法定稳定词,仅随《广告法》修订更新。
