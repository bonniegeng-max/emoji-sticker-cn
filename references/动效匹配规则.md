# 动效匹配规则(情绪 × 主体 → 动效配方)

> 用途:`emoji-sticker-cn` 路线 D 的 L2 匹配规则表。agent 看图产出内容画像后,查本表选配方,交给 `scripts/animate_sticker.py --recipe <配方>` 渲染。
> 维护方式:持续更新;新增/调整配方走「规则更新与退出机制」(旧配方 `deprecated` 留痕,新配方 `active`,CHANGELOG 记版本)。
> **条目生命周期**:`pending-verify` → `active`(生效)→ `deprecated`(退出留痕)。

## 一、内容画像维度(agent 看图时输出)

| 维度 | 取值 |
|---|---|
| 主体类型 | person-full(人物全身)/ face(大头像)/ animal / object / text(文字型) |
| 情绪 | happy / angry / sad / surprised / shy / speechless / sleepy / neutral |
| 动态倾向 | 构图中已有的"势"(跳跃、倒下、冒火等,仅作配方微调参考) |
| 置信度 | high / low(low 时走兜底) |

## 二、匹配表(情绪 → 配方)`status: active`

| 情绪 | 配方 | 主动效 | 粒子 | 节奏 |
|---|---|---|---|---|
| happy | `happy` | 蓄力蹲→弹跳(抛物线+空中拉伸)→落地压扁→回弹呼吸 | ★×3-4 闪烁 | 中速,约 1.2s/循环 |
| angry | `angry` | 高频小幅震动 + 微旋转 | 💢×2 顶部两侧 | 最快,约 0.7s |
| sad | `sad` | 慢速下垂 + 低幅摇摆 | 💧×1 滑落 | 慢,约 2s |
| surprised | `surprised` | 整体放大过冲回弹 | !×1 弹出 | 极快,8 帧内 |
| shy | `shy` | 慢摇摆 + 轻微起伏 | 💗×2 上浮 | 慢,约 1.8s |
| speechless | `speechless` | 近静止微呼吸 | …×1 + 💧×1 | 极慢 |
| sleepy | `sleepy` | 呼吸 ±2% | Zzz×3 逐个升起 | 极慢,约 1.8s |
| neutral | `neutral` | 呼吸 ±2.5%(待机) | 无 | 极慢 |
| (文字型主体) | `text` | 整体 zoom 强调脉冲 + 微震 | 无 | 中速 |

### 兜底规则
- 画像置信度 low / 情绪无法判断 → **neutral**(宁可轻微也不生硬)
- 主体为文字为主 → `text`
- 混合情绪(如"又气又笑") → 取更强的一类,或问用户一次

### 兼容映射(v1 动效名)
`bounce→happy`、`shake→angry`、`pulse→neutral`、`wobble→shy`

## 三、粒子符号表(程序化绘制,零素材)

| 符号 | kind | 绘制方式 | 颜色 |
|---|---|---|---|
| 星星 | star | 五角星多边形 | 主体主色(提亮保可见) |
| 怒气纹 | anger | 四条放射短线(💢近似) | 红 (230,60,60) |
| 汗滴 | drop | 圆+三角水滴形 | 蓝 (120,180,240) |
| 爱心 | heart | 双圆+三角 | 粉 (240,90,120) |
| Zzz | zzz | 文字"Z"递增升起 | 蓝紫 (150,150,255) |
| 感叹号 | excl | 文字"!" | 主体主色 |
| 省略号 | dots | 文字"…" | 灰 (130,130,130) |

风格约定:极简几何风(用户已确认接受);尺寸小、分布于主体边缘,不抢主体戏。

## 四、渲染硬性约定(engine 侧保证)

1. 缓动:禁止线性运动;蓄力用 ease-in,落地回弹用 ease-out-back,呼吸用正弦。
2. 挤压拉伸守恒:sy 压缩则 sx ≈ 反比放大。
3. 首帧 = 情绪关键帧;f(0)=f(1) 保证无缝循环。
4. 不等帧时长:关键姿势(首帧/落地震/末帧)×1.8 时长,过渡帧标准时长。
5. 体积:微信 240×240 ≤500KB,超限自动降色(255→127→63)再抽帧。
6. 透明底全程保留(disposal=2)。

## 五、扩充约定
- 新增情绪(得意/疑问/比心/庆祝等候选):先在本文档登记配方定义(status: pending-verify)→ 引擎实现并 POC 验证 → 转 active + CHANGELOG。
- 粒子新增符号:同上,先登记绘制方式。
- v2.1 候选(未排期):多元素视差(文字/装饰与主体分离、分相位)。
