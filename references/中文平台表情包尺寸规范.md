# 中文平台表情包尺寸规范参考

> 用途:作为 `emoji-sticker-cn` skill 的裁切 / 命名知识源。
> 维护方式:本文件持续更新。每条记录带「核实状态」「status」「源 URL / 抓取日期」,平台规则变动时走 skill 的「规则更新与退出机制」(巡检 → diff 报告 → 用户确认 → 落盘)。
> 字段说明:`has_formal_spec` 标记是否有正式表情开放平台上架规范;无则为「内联图片」(聊天 / 评论 / 笔记配图自由上传,无固定成套规范)。
> **条目生命周期**:`pending-verify`(待复核)→ `active`(生效,唯一可执行依据)→ `deprecated`(已退出,保留留痕禁止使用)。

## 一、有正式规范的平台(可做合规上架)

### 微信表情开放平台 ✅ 官方核实
- 官网指南:https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=guide/index.html
- 制作规范:https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=guide/index.html#/makingSpecifications#specifications_stickers
- 审核标准:https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=guide/index.html#/auditingStandards#auditingStandards_demand
- 抓取日期:2026-09-12(全文复核,v1.3)/ 2026-09-28(FAQ 复核:上架修改限制)
- `has_formal_spec = true` | `status: active`
- **素材总表(官方 4 项)**:表情图(8–24 张)/ 详情页横幅 1 张 / 表情封面图 1 张 / 聊天面板图标 1 张;超出大小/尺寸会被**自动压缩裁剪**
- **主图(表情图)**:240 × 240 px;动态=GIF,静态=PNG/JPG/GIF;单文件 ≤ 500 KB;一套 8–24 张(单品 1 张);**同一套须统一动/静**;动态须循环播放、节奏流畅不卡顿;每张**不应有过多留白**;同套风格统一、**各图差异充分**
- **缩略图**:120 × 120 px(专辑)/ 240 × 240 px(单品);PNG;≤ 200 KB —— ⚠️ `status: pending-verify`(2026-09-12 官方素材总表已不列此素材,疑似平台自动生成;提交时以页面实际要求为准)
- **详情页横幅**:750 × 400 px;PNG/JPG;≤ 500 KB;**避免任何文字**;色调活泼明朗、与微信底色区分大、**避免白色背景**;**避免透明底**;内容与表情相关、有故事性;元素不得拉伸/压扁变形
- **封面图**:240 × 240 px;PNG;≤ 500 KB;须透明底;建议正面**半身/全身像(避免只头像)**;**无白色描边、避免锯齿、不要正方形边框**;少留白、少装饰;除纯文字类外避免出现文字;**不同专辑用不同封面**
- **聊天面板图标**:50 × 50 px;PNG;≤ 100 KB;透明底;建议仅含角色头部正面;无白色描边、避免锯齿、无方框边、少装饰;**不同专辑用不同图标**
- **赞赏引导图**:750 × 560;**致谢图**:750 × 750(GIF/PNG,≤ 500 KB,避免透明底);**赞赏引导语 5–15 个汉字**(可诙谐,建议与表情强关联)
- **特效**:≤ 480 × 480 px、≤ 24 帧、PNG、整体 ≤ 5 MB、**帧率固定 12 帧/秒**
- **背景要求**:封面/图标/缩略须透明底(无白描边、无锯齿);横幅/赞赏图/致谢图避免透明
- **文案规范**:
  - 专辑名称 ≤ 8 汉字、无标点无空格、**5 字内显示最佳**、避免与已有专辑重名(`status: active`;旧条目「单品名 ≤4 汉字」已 `deprecated`——4 字限制实为含义词规则)
  - 介绍 ≤ 80 汉字;版权信息 ≤ 10 汉字(未注册版权填设计师/工作室名)
  - 含义词:≤ 4 汉字、用普通话、避免标点、**同套不重复**、适合聊天场景
  - 文字信息用中文为主,避免生僻字,**不能使用表情符号和特殊字符**
- **文字类表情**:以文字为主须有动态或图案设计且**与含义匹配——无意义的缩放/平移/晃动/闪烁不能过审**;同套文字表情动态不得高度相似;大段歌词/诗歌/广告/标语不能过审
- **表情形象系统**(新功能,官方核实):可创建「表情形象」= 角色名(≤8 字,可对应具体角色,勿泛称)+ 头像(240×240 PNG ≤500KB,透明底,半身/全身)+ 聊天页图标(50×50)+ 简介(≤80 字);已上架作品可挂到形象下(**一套作品仅可挂一个形象,仅有 1 次更换机会**);形象有合集页,有机会被关联推荐 → **运营建议:主角起名并创建形象**
- **审核红线速记**(详情见官方审核标准页):充分差异(仅文字/细节不同、动画高度相似均拒);图内文字清晰无错别字、文明用语;无广告/导流/二维码/联系方式;无医疗金融烟酒等限制类;不得与官方已发布作品雷同;emoji 素材二创不能开赞赏;侵权/肖像须授权文件
- **上架修改限制**:上架状态作品**每自然月限用一次**上架表情修改,修改后重新排队审核;待审核 / 被驳回 / 审核通过状态可直接修改(`status: active`,官方 FAQ,2026-09-28 复核)
- 注:微信是唯一有完整中文上架规范的主流平台,本 skill 的「合规上架」以微信为主目标。

## 三、无正式规范(内联自定义图片为主)

| 平台 | 现状 | 参考限制(非官方强制) | 核实状态 |
|---|---|---|---|
| **抖音 / 抖币表情** | 聊天 / 评论自定义 GIF,无公开开放平台 | 经验值 240–1000 px、GIF / WebP ≤ 5 MB;审核敏感 / 侵权 | 内联,无规范 |
| **小红书** | 笔记配图内联,无表情商店 | 建议 1080 × 1080;GIF 常被转静态 | 内联 |
| **新浪微博** | 系统表情 + 相册自定义图 | 自定义图 ≤ 500 KB,JPG / PNG / GIF;无成套规范 | 内联 |
| **支付宝** | 聊天自定义表情,无开放平台 | 来源冲突(200×200/30KB vs 240×240/5MB),**数据不可靠** | 内联,待核实 |
| **百度贴吧** | 「贴吧实验室」内联自定义图 | 建议 ≤ 200 × 200,PNG / JPG;无成套规范 | 内联 |
| **钉钉** | 企业自定义表情,类似飞书 | 无独立公开规范汇总 | 内联,企业后台 |

## 四、使用约定(给 skill)
1. 微信 = 合规上架主目标,严格按上方尺寸 / 透明底 / 命名执行。
2. 抖音 / 小红书 / 微博 = 走「笔记配图 / 聊天表情」路线,按上方建议尺寸输出,不强求成套。
3. 执行依据 = `status: active` 条目;`pending-verify` 数据须提示用户复核;`deprecated` 一律不用。任何「单文件上限 / 尺寸」改动,先比对 `核实状态`:官方 > 教程 > 营销文,勿把二手攻略当规范。
4. 规则变更走 skill 的「规则更新与退出机制」:旧值改 `deprecated`(留痕)→ 新值 `active` 入库 → CHANGELOG 追加一行。新增 / 变更平台时同样在此追加条目并填 `源 URL` + `抓取日期`。
