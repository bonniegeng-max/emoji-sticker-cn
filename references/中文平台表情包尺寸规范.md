# 中文平台表情包尺寸规范参考

> 用途:作为 `emoji-sticker-cn` skill 的裁切 / 命名知识源。
> 维护方式:本文件持续更新。每条记录带「核实状态」「status」「源 URL / 抓取日期」,平台规则变动时走 skill 的「规则更新与退出机制」(巡检 → diff 报告 → 用户确认 → 落盘)。
> 字段说明:`has_formal_spec` 标记是否有正式表情开放平台上架规范;无则为「内联图片」(聊天 / 评论 / 笔记配图自由上传,无固定成套规范)。
> **条目生命周期**:`pending-verify`(待复核)→ `active`(生效,唯一可执行依据)→ `deprecated`(已退出,保留留痕禁止使用)。

## 一、有正式规范的平台(可做合规上架)

### 微信表情开放平台 ✅ 官方核实
- 官网指南(制作规范原文):https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=guide/index.html#/makingSpecifications
- 审核标准原文:https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=guide/index.html#/auditingStandards
- 抓取日期:2026-08-25(2026-08-27 复核修正主图透明口径)
- `has_formal_spec = true` | `status: active`
- **主图**:240 × 240 px;静态 PNG / JPG / GIF、动态 GIF;单文件 ≤ 500 KB;一套 8–24 张(单品可 1 张);动态须循环播放、节奏流畅
- **背景要求**:主图**不强制透明**(照片型表情合法,官方明文);插画型建议透明;**须透明的只有封面图与聊天面板图标**;详情页横幅**避免透明背景**
- **缩略图**:120 × 120 px(专辑)/ 240 × 240 px(单品);PNG;≤ 200 KB;与主图一一对应
- **详情页横幅**:750 × 400 px;PNG / JPG;≤ 500 KB;禁透明底、禁纯白底、画面内**避免任何文字**、色调活泼与微信底色区分
- **封面图**:240 × 240 px;PNG;≤ 500 KB;须透明底;建议正面半身/全身像(避免只头部);无白描边、无正方形边框
- **聊天面板图标**:50 × 50 px;PNG;≤ 100 KB;须透明底;建议头部正面特写
- **赞赏引导图**:750 × 560;致谢图:750 × 750(PNG/JPG/GIF,≤ 500 KB);避免透明背景
- **特效**:≤ 480 × 480 px、≤ 24 帧、PNG、整体 ≤ 5 MB
- **文案字段硬约束**:表情名称 ≤ 8 汉字(≤5 最佳,无标点空格);介绍 ≤ 80 汉字;版权信息 ≤ 10 汉字;**含义词 ≤ 4 汉字、避免标点、同套不重复**(含义词=用户搜索词,非画面台词)
- **付费表情**:10 微信豆定价档;已在其他平台上架的作品不可作为付费表情重复投稿
- **超规格后果**:超出尺寸/体积的素材**不拒收不报错,被静默压缩裁剪**(主体可能被裁掉)
- **命名**:数字编号 01,02,03…(主图与缩略图编号一致)
- 注:微信是唯一有完整中文上架规范的主流平台,本 skill 的「合规上架」以微信为主目标。审核拒因见 `微信表情审核标准与高频拒因.md`。

## 四、使用约定(给 skill)
1. 微信 = 合规上架主目标,严格按上方尺寸 / 透明底 / 命名执行。
2. 抖音 / 小红书 / 微博 = 走「笔记配图 / 聊天表情」路线,按上方建议尺寸输出,不强求成套。
3. 执行依据 = `status: active` 条目;`pending-verify` 数据须提示用户复核;`deprecated` 一律不用。任何「单文件上限 / 尺寸」改动,先比对 `核实状态`:官方 > 教程 > 营销文,勿把二手攻略当规范。
4. 规则变更走 skill 的「规则更新与退出机制」:旧值改 `deprecated`(留痕)→ 新值 `active` 入库 → CHANGELOG 追加一行。新增 / 变更平台时同样在此追加条目并填 `源 URL` + `抓取日期`。
