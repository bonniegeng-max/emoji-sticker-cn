# 静态姿势动作库（语义/情绪 → 单帧姿势 · 通用可复用）

> 用途：表情包 / 漫画 / 贴纸等**静态出图**时，保证"画面姿势、表情、场景元素"与"意图/文字语义"一致——解决"要『加油』却出了『举书摊手』"这类 AI 出图语义错位。生成前 agent 查本表取一行（含姿势拆解 + prompt_en 英文词串），把姿势显式写进生图 prompt。
> **通用性**：本表为「意图 × 变体」结构，不写死表情包专属词，可被 text-to-comic 等其它视觉 skill 复用（复用时忽略平台尺寸列即可）。
> 维护方式：新增意图/变体先在表中登记（`pending-verify`）→ 实际出图 POC 验证 → 转 `active`；失效条目转 `deprecated` 留痕不删。**与 `动效匹配规则.md` 的关系**：本表管"静态单帧摆什么姿势"，动效表管"动态 GIF 怎么动"，两表以 `emo_key` 桥接，情绪定义域**只以动效表的 8 键为准**，本表不另造情绪名。

## 使用步骤（生成前「四步定姿势」，配合 SKILL.md 主流程）
1. **定意图**：把用户的话（"做个加油的""来个谢谢"）归一为唯一意图词（见下表 intent）；模糊时问用户一次，不猜。
2. **选变体**：按主体类型 subject 命中行，取 1 个 variant 的姿势组合；**同一套表情各张必须取不同 variant**（保证整套差异充分）。
3. **联动动效**：把该行 `emo_key` 对照 `动效匹配规则.md` 选 GIF 配方（路线 D）。
4. **组装 prompt**：把该行 `prompt_en`（+ 角色描述 + 风格词 + 背景约束）拼进 ImageGen prompt。

## text 型意图（主体=文字时）
- 画面以中文大字为主角（如"加油""冲鸭"）时，走动效表 `text` 配方做 GIF；静态图则整张为字 + 少量同语义装饰（加油→星星/火焰，开心→彩带）。
- 姿势语义由**文字本身**承载，此时无 pose 要求，但仍要求装饰元素与语义匹配。

## 硬性约定（执行时逐条过）
1. **文字策略**：语义由姿势+表情+场景表达，**画面默认不出现中文文字**（AI 渲染中文不稳）；用户**明示要文字**时才在 prompt 追加，并提示可能需重试。
2. **一致性自检（现）**：出图后请用户目检——姿势/表情/场景是否符合意图？不符则报「第几项不对」→ 只替换对应英文词重出，不整图重画。
3. **一致性自检（可选·模型支持读图才启用）**：AI 看图输出画像「期望 vs 实测」4 维（姿势/手部/面部/场景元素，各 0–2 分），任一 <2 分自动改词重出。
4. 主体从 person 换 animal/object 时：**保留核心动作语义**（如 cheer-a 的"上举握拳"→ 动物举爪），只换主体词，不得改动作语义。
5. 一条 intent 允许多 variant（a/b/…），整套取图时各张 variant 不重复。
